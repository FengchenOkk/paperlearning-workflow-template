# Canonical data model

Implemented tables: papers, paper_pages, source_spans, source_anchors, knowledge_nodes, knowledge_edges, evidence, jobs, verification_records, claims, equations and figures. IDs are independent of filenames; deduplication uses SHA-256. Derived source IDs keep their original stable namespace while pipeline metadata records extraction revisions. Paper node ID is the paper UUID. Both nodes and edges carry epistemic/verification status and provenance; candidate labels preserve source wording.

Foreign keys connect graph endpoints, paper ownership, source spans and anchors. Evidence points to one node and anchor. Scientific edges carry anchor IDs and fail validation without same-paper provenance. Source text is immutable after parsing. Anchors retain exact block text, offsets, PDF coordinates and document hash. Bounding boxes use the unrotated PyMuPDF page coordinate system and are transformed for rotated page rendering.

Claims/equations/figures are one-to-one subtypes keyed by canonical node FK, not additional graphs. Text/status/version stay on that node. Assumptions, supporting entity IDs, equation definitions/uses/derivations and figure observations/claims are projections of canonical edges. Source-attribution Evidence identifies wording, not scientific support. Claim support strength stays NOT_ASSESSED. Equation normalization, LaTeX, symbols and meanings remain unknown unless separately recorded with provenance and epistemic status. Figure caption, surrounding text, visual observations and AI interpretations have separate channels. The current parser cannot establish visual-region evidence.

Source anchors have TEXT_BLOCK precision. Section membership, image regions and precise equation/glyph boundaries are not guessed. Equation/figure references resolve through subtype source-anchor FKs; table/section references remain candidate associations. Reviews bind explicit scope, source hash, prior version and content/evidence fingerprint. API computes review_current without a second state store. Legacy reviews are preserved as unscoped and flagged for reconsideration.

Domain contracts enforce type/layer and basic endpoint invariants. Provenance JSON IDs still lack SQL FKs and enum/status strings lack comprehensive SQL checks; integrity reports detect violations. Deferred: verified section/reference hierarchy, table cells, translations, analyses/provider runs, entity resolution and learning evaluation. Storage fields are not completed scientific engines. PostgreSQL runtime remains unverified locally; SQLite migrations and populated-v1 preservation are tested.

Durable jobs contain run/input/version metadata and real component status. READY describes successful parsing/extraction, not scientific verification. PARTIAL records missing extractable text or unsupported source components. Re-uploading a document returns its existing paper/job rather than replacing human edits or invoking AI.
