## Vision and scientific constraints

PaperGraph is a local-first scientific-paper analysis and evidence-navigation platform. The implemented foundation is PDF → persisted source structure → candidate scientific objects → canonical graph → original evidence/page/block navigation. Research-grade understanding, scholarly retrieval and reviewed first-principles learning remain future capabilities.

- Never fabricate scientific facts, citations, equations, experimental conditions, source locations, progress or human acceptances.
- Source attribution answers what the paper says and where; it does not establish scientific validity. Preserve literal source wording, author assertions, observed data, external knowledge, AI interpretation, AI derivation and unknowns as distinct categories.
- A knowledge graph is a canonical data model. UI layouts, filtered projections and exports read that model; they are not additional truth stores.
- Extraction produces candidates. Confidence, co-occurrence, successful parsing and structural provenance are not scientific verification or dependence.
- No paper/title/author/material-specific hardcoding, manually prepared answer graph or gold-data input in production extraction. Evaluation inputs stay outside application runtime.
