# 全文双语对照翻译

## 使用约定

- 按自然段、图注、表注或公式说明切成可核验的小段；每段必须有唯一 `id` 和 PDF 页码/图表锚点。
- `original` 与 `zh` 必须一一对应。公式、变量、单位、图注、表注和脚注不可省略。
- 首次出现的术语保留英文；不能确定的译法标 `[待核验]`，不要静默修正。
- Codex 的解释放入 `03-deep-reading.md`，不要混入译文。
- 修改后运行 `npm run literature:render -- <本文件路径>`，生成并排阅读的 `02-translation.html`。
