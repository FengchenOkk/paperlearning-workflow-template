# 科研资料

这里存放多个工作流共享的科研材料。单个课题专用的材料优先放在对应 `workstreams/WS-###-slug/` 中。

建议按实际需要创建：

- `literature/`：论文清单、检索式、筛选记录和阅读笔记。
- `data/`：数据说明、来源、许可和处理记录；大型数据不直接提交版本库。
- `experiments/`：跨工作流的实验规范、环境和复现说明。
- `methods/`：通用方法、评估指标和分析约定。

[`literature/`](literature/README.md) 保存 Zotero 生成索引和逐篇阅读包；论文原件始终留在 Zotero。除说明文件外，`research/` 默认被忽略，避免将真实论文信息、机器环境、数据或研究过程推送到公共模板仓库。

任何本地材料至少记录来源、获取日期、版本、许可和使用限制。需要公开的方法模板应脱敏后放入新的公共 `templates/` 或 `examples/` 目录。
